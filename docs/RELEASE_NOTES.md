# v0.9.6

本版本加入了大家一直在等的**更新中心**和**卸载清理**，并修复了 Pokeldn 精简运行时解压到 99% 后提示未安装的问题。

## 新增

- **更新中心**：设置中新增「更新」页，可检查 GitHub 最新版本、查看更新日志、跳过某个版本。
- **安装版直接下载 Setup**：安装版自动选择 Setup 包，下载完成后由应用退出并启动安装程序；安装完成后自动重新打开。
- **便携版可选 ZIP 更新**：便携版下载新的 portable ZIP 后，在原目录替换程序文件，并保留 `cache` 中的资源、地图标注和自定义图片。
- **手动更新包**：网络下载失败时，可以自己从 GitHub 下载 ZIP 或 Setup，再在更新中心选择文件。程序会校验包结构、版本和可选的 SHA256。
- **失败原因提示**：对无网络、代理、TLS、GitHub 403/404/429/5xx、磁盘空间不足、权限不足、文件被占用、包损坏等情况给出中文提示。
- **卸载数据清单**：安装版的卸载程序会列出缓存、日志、设置、更新包，可自行勾选是否随程序一起清理。
- **应用内清理中心**：设置 → 更新页下方可以查看各类数据占用空间，并选择清理资源缓存、日志、旧更新包等。

## 修复

- 修复 Pokeldn 精简运行时解压后目录层级错误：资源下载到 99% 后提示未安装的问题。已下载过失败资源的用户，重新点击一次「自动下载」即可，无需删除整个 cache。

## 下载哪个

- **安装版**：适合大多数用户。下载 Setup，按向导安装，之后更新也在应用内完成。
- **便携版**：解压即用。更新时程序会替换自身目录，`cache` 会保留。建议解压到较短路径，例如 `D:\PLA-MMO-Seed-Path`。

## 注意

- 第一次从 v0.9.5 升级到 v0.9.6 需要手动下载并安装一次；v0.9.5 本身没有更新中心。从 v0.9.6 开始可在应用内检查和安装后续版本。
- 更新不会包含 `prod.keys`、用户存档、日志或 `cache` 中的资源。
- GitHub 下载仍可能受地区、代理、防火墙或杀毒软件影响；失败时请使用「手动更新包」。
- 安装包未做商业代码签名，Windows SmartScreen 可能提示“未知发布者”，请核对 SHA256 后再运行。
