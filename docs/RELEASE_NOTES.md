# v0.9.7

本版本集中修复「设置中心 → 更新与维护」的排版问题，以及关闭设置窗口时偶发的一帧闪屏。

## 修复

- 更新与维护页改为与其它设置页一致的卡片分区，检查更新、手动更新、清理本地数据之间重新留出间距，不再贴边。
- 手动更新不再使用占满整行的原生文件框，改为「选择文件 + 文件名 + 校验 + 安装」的紧凑按钮行；窄窗口和大字号下会自动换行。
- 清理列表在窄窗口下保持单列布局，路径和说明不再挤出卡片。
- 修复关闭设置时退场动画与隐藏定时器同时结束造成的闪屏：现在等遮罩淡出动画真正结束后再隐藏，并保留超时兜底。
- 便携版更新完成后自动清理旧版本备份；若旧程序仍被 WebView2 占用，会在下次启动时继续清理，并可在「清理本地数据」中查看和删除。

## 更新

- 从 v0.9.6 可以直接在应用内「检查更新」升级到本版本。
- v0.9.5 及更早版本没有更新中心，仍需手动下载安装一次。
- 更新不会删除 `cache`、宝可梦图片、地图标注或你的设置。

## 注意

- 安装包未做商业代码签名，Windows SmartScreen 可能提示“未知发布者”，请核对 SHA256 后再运行。
- 便携版建议解压到较短路径，例如 `D:\PLA-MMO-Seed-Path`。
