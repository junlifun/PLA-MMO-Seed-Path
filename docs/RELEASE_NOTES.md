# v0.9.14

新增相邻版本增量更新，减少每次升级的下载量。

## 新增

- 0.9.13 → 0.9.14 优先提供增量包，只包含发生变化的程序文件，不再重复下载 54 MB 的完整便携包。
- 下载前校验本地文件是否仍与 0.9.13 基线一致；文件被修改过或版本跨度太大时，自动改用完整包，避免装坏。
- 增量包安装前校验每个待替换/删除文件的来源 SHA256；安装失败会恢复已改动的文件并重新启动旧版本。
- 更新页面会标明本次是「增量包」还是「完整包」，并显示对应下载大小。

## 说明

- 首次安装、跨多个版本升级，或手动选择更新包时，仍然使用完整 Setup / 便携包。
- 增量包只替换程序文件，不会删除 `cache`、地图标注、自定义图片或设置。
- GitHub Release 同时保留完整包和增量包；自动更新失败时可直接下载完整包覆盖。

# v0.9.13

联机采集自动收尾、更新安装提示和界面反馈改进；本次一并发布此前未发布的 v0.9.11、v0.9.12 改动。

## 新增

- 联机采集时，检测到 Switch 已离开交换后等待 6 秒；若没有新记录，自动用已收录的 2–3 只反推 Seed，无需再手动点「完成采集」。
- Switch 重新连接或收到新的宝可梦记录时，会自动取消本次自动计算；连接中断时仍可手动停止后重新采集。
- 每收录一只宝可梦，对应卡片背景变为浅绿色，明确提示已交换成功。
- 点击安装更新后显示「正在安装」遮罩和进度提示，不再确认后直接黑屏退出；安装版改为显示安装程序进度窗口。
- 自动更新支持暂停/继续；选择手动更新包时，正在进行的自动下载会自动暂停。
- 联机采集支持用已收集的 2–3 只宝可梦直接反推，不必强行凑齐 4 只。
- 联机设置新增「连接人名字」，默认 `seed`，可改成 1–12 个字符。

## 修复

- 顶部出现「最近一次计算失败」「本地引擎未通过验证」或更新提示时，侧栏高度会同步缩短，「计算路径」按钮不再掉到窗口下方。
- 无线板未安装、联机启动失败等错误改为页面顶部全局提示，不再只显示在左上角 Seed 卡片下方。
- 已收录 2–3 只时，提示不再一直催第 4 只；会提示可以直接完成，并说明 4 只最稳。

## 说明

- 兼容原 `cache`、设置和更新包；更新不会删除已下载的联机运行时。
- 安装包未做商业代码签名，Windows SmartScreen 可能提示「未知发布者」，请核对 SHA256 后再运行。

# v0.9.10

修复联机测 Seed 启动后以退出代码 2 结束的问题。

## 修复

- 精简运行时补齐 `python-netlink`（`netlink`）。`LDN/ldn/wlan.py` 在导入时会加载该模块，即使实际由 ESP32 托管网络也不能缺少。
- 自带 Python 运行时同样内置 `netlink`，升级程序即可修复，无需删除已有的 `cache/pokeldn-slim`。
- 精简运行时更新为 `pokeldn-slim-v0.66.12-r3.zip`。
- 联机采集启动失败时，界面会显示真实的 `[pla]` 错误；退出代码 2 会附带最近一条错误详情，而不是只提示“请检查右侧输出”。

## 说明

- 本版本仍兼容 `junlifun` 与旧名 `Yuutalin` 的仓库地址。
- 安装包未做商业代码签名，Windows SmartScreen 可能提示“未知发布者”，请核对 SHA256 后再运行。
- 便携版建议解压到较短路径，例如 `D:\PLA-MMO-Seed-Path`。
